# Ping Pong

Ping Pong is a powerful version of the classic arcade game, designed with an extremely aesthetic, modern, and intuitive design. It offers unique and exceptional versatility, so much so that it can literally be played and run even within plain text applications like Windows Notes or TextEdit on macOS.

Main Features
Dynamic and responsive gameplay for exciting challenges.

Aesthetic, modern, and clean design for a fluid visual experience.

Maximum versatility: lightweight and portable, it runs anywhere, even within text editors like Windows Notes and macOS TextEdit.
